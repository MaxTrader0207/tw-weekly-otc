# tw-weekly-otc

台股週報儀表板的上櫃資料來源。櫃買中心會擋 Cloudflare 機房的連線，所以改由 GitHub Actions 每個交易日去抓，存成 `data/otc_week.json`，儀表板的 Cloudflare Worker 每天 19:00、22:00 建置時讀取。

- **排程（台灣時間，週一～週五）：** 17:30、18:30（備援）、21:30（補抓）
- **資料來源：** 證券櫃檯買賣中心「上櫃股票每日收盤行情」「三大法人買賣明細資訊」
- **範圍：** 上櫃普通股（代號 1～9 開頭的 4 位數），不含 ETF、債券、權證
- **原則：** 查不到就不寫；欄位格式不符時整次執行失敗，不產生錯誤數字

| 路徑 | 內容 |
|---|---|
| `scripts/fetch_otc.mjs` | 抓取與整理程式（Node.js 20，不需要安裝套件） |
| `.github/workflows/otc.yml` | 排程設定 |
| `data/otc_week.json` | 給儀表板讀的資料：基準日、本週各交易日行情與三大法人、近 20 日 K 線 |
| `cache/` | 每日原始資料快取，避免重複抓取；保留 60 天 |

手動執行：Actions → 抓取上櫃資料 → Run workflow。
